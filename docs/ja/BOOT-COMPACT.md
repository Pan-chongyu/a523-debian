# 圧縮カーネルによる起動最適化

[English](../BOOT-COMPACT.md) · [简体中文](../zh-CN/BOOT-COMPACT.md) · [Español](../es/BOOT-COMPACT.md)

元の実機で通常再起動を2回検証しました。読み込みと CRC は **5.00 秒から 2.22 / 2.22 秒**に短縮し、新しい展開・移動・検証・キャッシュ処理は **0.265 / 0.265 秒**です。読み込み量は約55%減り、展開後のカーネルは元と完全一致します。デスクトップの5プロセスがそろう時刻は Linux 起動後 **19.83 / 19.96 秒**（直前は21.64秒）です。操作可能な画面の時刻ではありません。

最初の星空の猫の画像はカウンターで **5.912 / 5.916 秒**のままで、この層による短縮ではありません。電源ボタンからの再計測は未実施です。境界検証付き LZ4、一時的な RAM 恒等マップ/キャッシュ、PoC への出力清掃を使用し、Linux の前に MMU/データキャッシュと EL2 レジスターを元に戻します。DRAM トレーニング、全 CRC、フォールバック、USB 復旧、画像のピクセルは維持します。initramfs の重複 BusyBox と文書、強制早期 UART デバッグ出力を除きました。

両回とも CPU、2.5GiB のメモリー、GPU 描画/計算、600フレームのハードウェア動画デコード、ストレージの複合試験に合格しました。失敗サービスと検出したメモリー/MMC/IOMMU/表示エラーは0です。CPU performance 1416/1800MHz、温度制限付き GPU 600MHz 要求、HS200 100MHz と2GiB zram を維持します。右横向きとタッチ行列の自動確認に加え、2回目の起動後に所有者が画像・デスクトップ・タッチの正常動作を確認しました。長期信頼性を証明する試験ではありません。

これは研究ソースと[測定結果](../../reports/boot-compact-20261114.json)です。**公開イメージ `v0.1.0-20261114` とフラッシャー `v0.2.0` は未更新です。** 汎用更新パッケージではありません。履歴の元実機用資料が必要です。未採用の無キャッシュ試験、実機復元、実装と測定範囲は [English](../BOOT-COMPACT.md) を参照してください。

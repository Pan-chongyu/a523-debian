# インストール手順

[简体中文](../zh-CN/FLASHING.md) · [English](../en/FLASHING.md) · [Español](../es/FLASHING.md)

## 対応ハードウェア

**TZX P30A523_20T5G**（刻印 `TZX P30A523-56T5G-240321`）、A523/sun55iw3p1、**LPDDR3 4 GiB**、**UEM 128 GB eMMC**（512 バイト × 244318208 セクター）、JL_M1010WX92_M4027 800×1280 DSI パネル専用です。FEL SoC ID `0x00189000` と CID 製品プレフィックス `3e01ff55454d2020` も検証します。自動検査だけでは基板全体を識別できません。基板の刻印を必ず確認してください。

実験的プレリリースです。元の端末では動作確認済みですが、匿名化した公開イメージの全書き込みは実機未検証です。**端末の既存データはすべて置き換えられ、自動バックアップはありません。** 全セクターの安全消去ではありません。安定した電源とデータ通信可能な USB ケーブルを使用してください。

## Windows

1. [Releases](https://github.com/Pan-chongyu/a523-debian/releases) から `a523-debian-flasher-v0.1.0-20261114.zip` をダウンロードし、全ファイルを展開します。
2. Python 3.10 以降と Python Launcher（`py`）をインストールします。依存関係と約 1 GB 規模のイメージのためにインターネット接続、8 GB 以上の空き容量が必要です。
3. 自分の端末で確認済みのボタン操作で **FEL** に入り、1 台だけ接続します。デバイスマネージャーで USB **1f3a:efe8** を確認します。ボタンの組み合わせは機種により異なります。
4. 必要なら [Zadig](https://zadig.akeo.ie/) で **その FEL デバイスだけ**に WinUSB を導入します。後から現れるストレージ、COM、ネットワークのドライバーは変更しません。
5. **flash.cmd** をダブルクリックし、管理者権限の要求を承認します。基板情報を確認し **FLASH** と入力します。ダウンロード、SHA256 検証、一時インストーラー起動、ディスク選択、書き込みと読み戻し、GPT 拡張を自動実行します。
6. 完了まで電源を切らないでください。初回起動でルートファイルシステムが拡張されます。自動再起動できない場合は USB を安全に切り離し、電源ボタンで再起動します。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\flash.ps1 -Language ja
powershell -NoProfile -ExecutionPolicy Bypass -File .\flash.ps1 -Language ja -DryRun
```

`-DryRun` はダウンロードと検証のみで、USB やディスクにはアクセスしません。実書き込みには管理者権限が必要です。任意のディスク番号は指定できず、容量と今回のランダムセッション識別子が一致する USB ディスクだけを選びます。Windows のシステム・起動ディスクは除外します。

## Linux

```sh
sudo apt install python3 python3-venv curl libusb-1.0-0
chmod +x flash.sh
sudo ./flash.sh --lang ja
```

先に FEL に入り、対象を 1 台だけ接続します。自動マウントされた端末のパーティションはアンマウントしてください。`sudo ./flash.sh --lang ja --dry-run` で事前検証できます。macOS のディスク書き込みは未実装です。

## 初回起動

ローカルのユーザー名・パスワードは **debian / debian**。デスクトップは自動ログインし、右回転の横向き表示です。直ちに `passwd` で変更してください。root はロック済み、SSH は無効です。変更後、必要な場合だけ `sudo systemctl enable --now ssh` を実行します。

USB ネットワークは、ホスト側を `192.168.77.1`、マスク `255.255.255.252`、ゲートウェイなしに設定します。端末は `192.168.77.2` で、`ssh debian@192.168.77.2` で接続します。端末 ID と SSH ホスト鍵は初回に生成します。元の所有者の鍵、Wi-Fi 情報、ブラウザー履歴は含みません。

CPU 性能モード、Panfrost、HS200、2 GiB zram を設定済みで、ブラウザーの事前起動は無効です。温度保護は有効です。未対応機能はトップページを参照してください。

## 復旧

ダウンロード中断時は再実行できます。`.part` の再開と SHA256 検証を行います。不一致のファイルはキャッシュから削除して再取得し、検証を無効化しないでください。既定のキャッシュは `~/.cache/a523-debian/v0.1.0-20261114` です。

FEL が見つからない場合はケーブル、USB ID、WinUSB、他の接続機器を確認します。180 秒以内に USB ストレージが現れない、または書き込みが失敗した場合は強制電源オフし、FEL に戻して再実行します。イメージの書き込みは最初から行います。一時インストーラーはユーザー領域の起動データを変更するため、失敗後は旧 OS が起動しない場合があります。

CID・容量の検査を回避しないでください。boot0/boot1/RPMB とヒューズは書き換えません。復旧には利用可能な FEL と正しい DRAM 設定が必要です。問題報告からパスワード、秘密鍵、eMMC シリアル番号を除去してください。

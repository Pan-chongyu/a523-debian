# 起動処理の最適化

[English](../BOOT-STARTUP.md) · [简体中文](../zh-CN/BOOT-STARTUP.md) · [Español](../es/BOOT-STARTUP.md)

元の実機で通常再起動を2回検証しました。5個のデスクトッププロセスがそろう時刻は Linux 起動後 **21.73 / 21.64 秒**で、基準の **25.48 秒**から **3.75 / 3.84 秒**短縮しました。画面が操作可能になる時刻や電源ボタンからの実測時間ではありません。変更していない星空の猫の起動画面はハードウェアカウンターで **5.920 / 5.939 秒**でした。

256MiB のメモリー検証を早め、電源オフ処理の登録後に CPU の電圧を変更し、検証済み HS200/100MHz を GPU と LightDM より前に有効化します。重複した外側の GPU 検証と診断時の全体同期を除きました。直前の GPU 検証、DRAM トレーニング、CRC、温度保護、ロールバックは維持します。Bluetooth は LightDM の後にバックグラウンドで初期化し、元のコマンドと待機を維持します。

Bluetooth は約15秒かかるため、全起動ジョブの完了時間はデスクトップの時刻とは異なり、遅くなる場合があります。両回とも CPU、2.5GiB メモリー、GPU 描画/計算、600フレームの動画ハードウェアデコード、ストレージ検証に合格し、失敗サービスと検出したメモリー/MMC/IOMMU/表示エラーは0でした。右横向きとタッチ変換は自動確認済みですが、最終版の目視確認と電源ボタン計測は未実施です。長期信頼性を証明する試験ではありません。

これは研究ソースと[測定結果](../../reports/boot-startup-20261114.json)の更新です。**公開イメージ `v0.1.0-20261114` とフラッシャー `v0.2.0` は未更新です。** 元の実機専用のハッシュと検証記録に依存し、汎用更新パッケージではありません。詳細と不採用の試験は [English](../BOOT-STARTUP.md) を参照してください。

# 起動画像の表示時間

[English](../BOOT-SPLASH-SPEED.md) · [简体中文](../zh-CN/BOOT-SPLASH-SPEED.md) · [Español](../es/BOOT-SPLASH-SPEED.md)

元の実機では、星空の猫の画像出力が **7.887 秒から 5.889 / 5.918 秒**に短縮されました。24MHz の起動カウンターで画像転送と走査確認の完了を測った値です。電源ボタンからの実測時間やデスクトップ起動時間ではありません。最終版の目視確認と電源オフ後のボタン起動は未確認です。

検証済みの CPUA 1416MHz/1150mV を DRAM トレーニング前に適用し、画面電源の最低一秒の安定待ちをトレーニングと並行させます。必要な待ち時間、毎回のメモリトレーニング、画像データ、パネルのリセットと DSI 起動手順は維持されます。TF-A への移行前およびトレーニング失敗時に元の CPU 電圧とクロックを復元します。

二回の通常再起動と、それぞれ約 42–43 秒の CPU・2.5GiB メモリ・GPU・動画デコード・ストレージの混合テストに合格しました。右横向きの画面設定、タッチ行列、Bluetooth が自動復帰し、エラーや失敗サービスは検出されませんでした。温度・故障保護は有効です。これは長期安定性の保証ではありません。以前の中間候補では Bluetooth 初期化が一度失敗し、サービス再起動で復帰しています。

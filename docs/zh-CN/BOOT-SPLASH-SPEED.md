# 开屏图片提速

[English](../BOOT-SPLASH-SPEED.md) · [日本語](../ja/BOOT-SPLASH-SPEED.md) · [Español](../es/BOOT-SPLASH-SPEED.md)

原机现已安装提速版本，两次正常重启的星空猫图片输出计数为 **5.889 / 5.918 秒**，本轮原版基线为 **7.887 秒**，缩短约 **2 秒 / 25%**。这是图片提交、扫描验证后的 24MHz 硬件计数，不是按电源键秒表计时，也不是进入桌面时间。最终版目视和关机后按键开机尚待确认；用户较早反馈的“9s”属于中间候选。

训练前提前使用已验证的 CPUA 1416MHz/1150mV，把屏幕供电所需的完整一秒稳定等待与内存训练重叠。训练提前结束时仍补足等待，之后执行原有面板复位、DSI 唤醒与扫描验证。完整内存几何探测、每次重新训练、训练参数和图片像素/解码保留；不缓存 PHY 训练结果。交给 TF-A 前及训练失败时恢复原 CPU 电压和时钟。

两次启动均通过约 42–43 秒的 CPU、2.5GiB 内存、GPU 图形/计算、600 帧视频硬解和直接文件读写联合负载，最高温度分别为 73.320/72.345°C，零内存、MMC、IOMMU、显示错误及失败服务。向右横屏 1280×800、触摸矩阵和蓝牙自动恢复，OpenCL C3 与 SPIR-V 复测通过；保留温控和故障保护。有限测试不等于长期稳定性保证。

更早的仅提前 CPU 提频候选出现过一次蓝牙初始化超时，手动重启服务后恢复。最终重叠版本的两次启动未重现，原因尚未隔离。

[实测报告](../../reports/boot-splash-speed-20261114.json)区分原机与公开镜像。**镜像 `v0.1.0-20261114` 与刷机工具 `v0.2.0` 的 Release 文件未更新**，仍含原约 7.8 秒图片引导器。本次公开研究源码和结果，不提供可通刷的引导升级包；公开镜像的产品前缀检查及所有运行脚本哈希需另行构建并验证。

源码入口为 `research/firmware/boot_panel_early.c` 的 `TZX_PANEL_OVERLAP` 分支、`boot_logo_speed.c` 及 `research/tools/build_boot_logo_overlap.sh`，另有候选生成和 ARM 仿真脚本。它们依赖历史构建目录与精确原模板，见 [BUILD.md](../BUILD.md)，不可把原机安装器直接用于别的设备。未公开签名私钥或登录凭据。
